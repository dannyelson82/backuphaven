# Plugins

The guide for writing a plugin lives with the code, so the app can include it
in plugin development files:
[`backend/src/backuphaven/plugins/AUTHORING.md`](../../backend/src/backuphaven/plugins/AUTHORING.md).

- Bundled plugins: `backend/src/backuphaven/plugins/bundled/`
- Their fixtures: `backend/tests/plugin_fixtures/`
- Pull request checklist: `.github/PULL_REQUEST_TEMPLATE/plugin.md`
